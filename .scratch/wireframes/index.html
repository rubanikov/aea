AEA UI redesign — wireframe options

Low-fi greyscale wireframes · pick ONE calendar direction and ONE booking direction. Every frame includes the shared shell with the Light / Dark / System toggle; timezones use the "Eastern Time (New York)" label style; provider cancel now has a confirm step with reserved space for the future reason field.

Calendar directions (provider week view + patient date/slot picker)

  1. Option A — Google Classic GridTrue time-grid week: mini-month sidebar, hour ruler, duration-height blocks. Most authentic, biggest lift.
  2. Option B — Polished Strip + AgendaKeeps today's structure, restyled to Google's Schedule-view language. Smallest lift, least "calendar-like".
  3. Option C — Notion-style Week Board + Detail RailSeven stacked-card columns + persistent right detail rail with all actions. Whole week visible, medium lift.

Booking-flow directions (patient: provider/service → date → slot → confirm)

  1. Option 1 — Calendly three-pane cardContext rail | month | time list in one card; inline split-button confirm.
  2. Option 2 — Zocdoc slot-first directoryService filter → provider rows with inline 5-day slot grids; slot tap → one review page. Fewest taps, biggest data change.
  3. Option 3 — Square Appointments stepper4-step wizard with persistent summary rail and "Any available provider" fast path. Most guided, most steps.
