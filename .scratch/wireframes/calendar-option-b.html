Calendar — Option B: "Polished Strip + Agenda"

Direction: keeps the current structure exactly (Monday-first week strip + one selected day's agenda) but restyles it to Google Calendar's Schedule/Agenda view language: rounded day pills with per-day event dots, a strong time rail on the left of each row, a status-coded color bar per appointment, hover elevation, and row actions collapsed behind a kebab menu instead of three always-visible buttons. Borrowed from Google Calendar: the Schedule-view row anatomy (time rail → color bar → title/meta), the dot-marker density signal, and Today/chevron toolbar. Tradeoff: smallest lift — zero data/interaction rework, so it ships fastest, but it will never read as a "real calendar grid"; providers who want to see gaps between appointments spatially don't get that here.
